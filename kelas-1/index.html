si jenius jordan

React JS, sebuah pustaka JavaScript untuk membangun antarmuka pengguna (UI), memiliki sejarah yang menarik di balik pengembangannya. Awalnya, React dibuat oleh Jordan Walke, seorang insinyur perangkat lunak di Facebook. Ia terinspirasi oleh XHP, sebuah library komponen HTML untuk bahasa pemrograman PHP. Proyek ini, yang awalnya disebut "FaxJS", kemudian berevolusi menjadi React.
